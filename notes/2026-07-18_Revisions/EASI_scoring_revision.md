# EASI automatic-coverage scoring revision — 2026-07-18

Implements the reviewed method set from
`EASI_Final_Automatic_Coverage_Metrics_Old_vs_New_Review.xlsx` (13 metrics CRITICAL,
4 HIGH, 3 RETAIN/CLARIFY). Calculation and content only — the UI architecture,
report layout, modal structure and tooltip system are unchanged.

## The architectural change

`data/screening-methods.json` is now the single source of truth for every automated
formula, boundary, basis, limitation and citation. `easi/screening_methods.py`
evaluates it with a closed set of nine typed operators and never evaluates an arbitrary
expression. Everything downstream reads that one catalog:

- metric adapters call `evaluate()` and no longer bin values themselves;
- `easi/methods.py` projects catalog entries into the existing `ScoringMethod` shape, so
  `easi/method_plot.py` and the worksheet panels render unchanged;
- the criteria list is generated by `criteria_for()`, so it cannot describe a different
  quantity than the one scored;
- the V&V metric tables are generated by `scripts/build_method_tables.py`.

Before this, adapter math and the display catalog were declared separately and had
drifted: the panel claimed road density counted stormwater outfalls, flow alteration
reported a percent difference from baseline, and substrate claimed embeddedness while
computing a slope/agriculture composite.

## Calculation changes with the largest effect

- **Flow alteration** was dimensionally wrong — it divided the already-normalized
  `DamNrmStorWs` by drainage area again. Now `DOR% = 100 x storage / (1000 x runoff)`,
  banded 2% / 30%.
- **Floodplain engagement** binned a fabricated `BHR^(5/3)` recurrence curve. Now bins
  BHR directly at 1.3 / 1.5, with a geometry-verification warning below 1.0.
- **Low flow, substrate, biological integrity** now prefer connected NRSA 2018-19
  evidence (exact COMID, else an NLDI-confirmed mainstem site within 5 mi / 10 yr) and
  fall back to published StreamCat components. Proximity alone never qualifies.
- **Nutrients** use normalized WQP total N/P against the nine NRSA regional benchmarks
  instead of one national pair; station medians then the median of station medians, with
  exclusion counts retained.
- **Thermal** scores vulnerability from woody riparian cover and impervious cover. The
  air-temperature surrogate and WQP spot-temperature scoring are gone; WQP temperature is
  retained as unscored context.
- **Bank erosion** is a BHR susceptibility proxy that complete observed bank evidence
  supersedes, with the proxy preserved and still updating underneath.

## Missing data is never zero

Required inputs are explicit. An absent StreamCat class is unknown, not zero — the
riparian, agriculture and wetland accessors now return `None` if any expected field is
missing rather than summing the rest. A no-data outcome reports `None` and renders as a
dash; ECI averages only available sub-indices. Two latent red-zero bugs were fixed in
the summary panel, where a missing function score and an unavailable ECI were coerced to
`0` and drew the Non-Functioning colour.

## Coverage is reported in two dimensions

Availability coverage (rated / selected) is reported separately from the evidence
profile (observed / connected-nearby / published-model / screening-proxy / manual /
unavailable), with correlation notes when several metrics share `incision_geometry`,
`iwi_landscape` or `nrsa_field`. A full run reports "Complete screening coverage —
includes proxy-derived ratings". 20/20 means complete availability, not 20 independent
observations.

## Deliberately not changed

- STAF metric and function names in `easi-metrics.json` are untouched; the revised method
  identity travels as `methodTitle` and shows in the Scoring method panel and exports.
- The multi-source swap plumbing (`apply_source_choices`, `sourceVariants`) is retained
  for manually supplied evidence but no adapter populates it: every metric now resolves
  one fixed automatic hierarchy, so the automatic source picker no longer appears.
- No UI redesign — no new pane, drawer or modal, and no typography, spacing, colour,
  navigation or table-layout changes.

## Open items

- **Provisional (12 of 20)**: metrics 1, 2, 3, 8, 9, 10, 11, 13, 14, 17, 19, 20 carry STAF
  screening transitions rather than validated ecological thresholds. Hyporheic, habitat
  support, channel adjustment and bank instability are Low confidence; their weights,
  caps and bands await calibration. Wetland extent has no published basis for its 1%/5%
  classes and is regionally controlled.
- **V&V validation statistics are stale** — they describe the previous method set and are
  labelled as such in `easi-vnv.qmd`. Refreshing them needs a networked re-run of the
  SFARI corpus via `scripts/build_doc_assets.py`.
- `prG_BMMI` is read under six column spellings because a missed column silently demotes
  biological integrity to the weaker ICI/IWI tier. Worth confirming the actual StreamCat
  column name against a live response.
