# libs/

Reserved for `staf-core` — the future shared Python package for code currently
duplicated across the four apps (scoring rollup, watershed delineation,
datasources, basin/Bieger/geomorph calculations, and the cross-app STAF nav bar
with its app URLs). Until it exists, a change to any shared concern (for example
an app URL) must be mirrored in `docs/_data/apps.yml` and in each app under
`apps/`.
