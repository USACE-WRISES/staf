# Changelog

## v1.0.0 (2026-09-23)
- StreamCurves is a Windows desktop app: install it from the STAF releases page; it keeps itself up to date.
- A start page opens the app: New project, Open project, the assessment library, recent projects and what is new.
- A project is a folder with one .streamcurves file; your work saves as you go, and Save As keeps a copy.
- The assessment library lists every draft, preliminary and final version; open one to work on your own copy.
- Revised an assessment? Send your .streamcurves file to the maintainer, who publishes the next version.
- A new header, a one-row stage strip and a Project panel list every stage, its steps and the tools.
- Saved sessions (.streamcurves.json) and workbooks (.xlsx) open as new projects.
- The Region & data wizard keeps unfinished work: picks and a compiled table reopen where you left them.
