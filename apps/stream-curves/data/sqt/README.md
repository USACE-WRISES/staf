# State SQT curve registry

`registry.json` lists the published state Stream Quantification Tool (SQT) curves that
StreamCurves can offer as candidate curve sources: one record per state, metric and stratum.
It is generated by `scripts/build_sqt_registry.py`; do not edit it by hand.

Records come from the raw bins of the STAF metric library CSV
(`docs/assets/data/metric-library/Metric Library Complete *.csv`), not from the clamped
compiled curves. Each record is compared with the adapted SQT assessments in
`apps/library/assessments/*-sqt-adapted` (what DEEP scores today) and with any original SQT
file on disk. `streamcurves/sqt_registry.py` reads the registry (search, applicability checks,
frozen copies for projects).

```
py -3.12 scripts/build_sqt_registry.py                   # rebuild
py -3.12 scripts/build_sqt_registry.py --check           # exit 1 when this file is stale
py -3.12 scripts/build_sqt_registry.py --list-originals  # show what each original holds
```

## Record fields

| Field | Meaning |
|---|---|
| `key` | `sqt:<state>:<metric>:<stratum>`, stable while the source names do not change |
| `state`, `stateName`, `tool` | The issuing state and its tool |
| `edition`, `editionBasis` | Edition hint from the metric library References column, or null |
| `citation` | The source the metric library names (for example `Minnesota SQT`) |
| `originalMetricName`, `stafMetricId`, `function` | The SQT metric name, the STAF metric id and the STAF function crosswalk |
| `protocol` | Field protocol when a source states one, else null |
| `units`, `unitsBasis` | Units from a matched original; null when no source states them |
| `stratum`, `stratumName` | The stratum label as written, and without the state suffix |
| `streamTypes`, `geography` | Rosgen stream types and sub-state region named by the stratum |
| `form` | `piecewise`, `two-sided`, `categorical` or `threshold-table` |
| `direction` | `increasing`, `decreasing`, `two-sided` or `unknown` |
| `source` | CSV file, row (header is row 1) and stratification group |
| `originalValues` | The six field-value and index bins exactly as written, with parsed numbers |
| `thresholds` | Bins written as a threshold (such as `>3`) instead of a breakpoint |
| `normalizedPoints` | Points in ascending x on the 0 to 1 index, not clamped, not extended |
| `extrapolation`, `extrapolationBasis` | Past the last point: `flat` (the curve reaches 0 and 1), `linear` (an original extends its end segments until the index reaches 0 or 1) or `unknown` |
| `scoreScale` | SQT bands: Not Functioning below 0.30, At Risk below 0.70 (STAF and DEEP use 0.39 and 0.69) |
| `sourceLimits` | Limits the matched original states (for example ephemeral streams) |
| `fingerprints` | sha256 of the CSV cells used and of the points |
| `adaptedIn` | Each adapted assessment version that carries the curve, its points, and how they differ from the source row |
| `verification` | Status, the original it was checked against (file, sheet and cells, or page and table), reasons and the cell-by-cell comparison |
| `issues` | `{code, severity, detail}`; severity is `defect`, `warning` or `note` |
| `eligible` | False when any issue is a defect |

## Verification status

- `verified`: every value was matched to an original file on disk (values the record lacks lie on its line).
- `partially-verified`: matched to an original, but some values are rounded or differ slightly, or the original has breakpoints the record lacks.
- `unverified`: no original on file. STAF adaptation, not verified against the original. Still eligible.
- `defective`: a defect was found (for example swapped columns, a mislabelled stratum, one limb of a two-sided curve). Not eligible.

Only two partial originals ship with the app: `data/templates/MN-List-of-Metricsv2.0.xlsx`
(Minnesota SQT v2.0 list of metrics) and `data/templates/WISQT_Reference_Curves.xlsx`
(Wisconsin SQT reference curves). Every other record is unverified until an original is added.

## Adding originals

Put the original files in `D:\Data\staf-authoring\sqt-originals\<STATE>\` (or the folder named
by `STAF_SQT_ORIGINALS`) with a `sources.json` beside them, then rebuild. The shape, with
placeholders in angle brackets:

```json
{
  "state": "CO",
  "sources": [
    {
      "id": "<short id>",
      "file": "<workbook file name>",
      "tool": "Colorado Stream Quantification Tool",
      "edition": "<edition as printed in the file>",
      "citation": "<citation as printed in the file>",
      "layout": "reference-curves",
      "sheet": "<sheet name>",
      "match": {"<anchor cell>": {"metric": "<metric name>", "stratum": "<stratum>"}}
    },
    {
      "id": "<short id>",
      "file": "<manual file name>",
      "edition": "<edition>",
      "citation": "<citation>",
      "layout": "manual",
      "tables": [
        {"metric": "<metric name>", "stratum": "<stratum>", "page": "<page>",
         "table": "<table>", "values": ["<0>", "<0.29>", "<0.30>", "<0.69>", "<0.70>", "<1>"],
         "units": "<units as printed>"}
      ]
    }
  ]
}
```

- `layout` is `reference-curves` (a sheet of title, field value rows and an Index Value row, as
  in the WI file), `performance-standards` (one row per metric with a column per index level,
  as in the MN file) or `manual` (values typed from a page and table of a PDF or report).
- `match` maps a table to a record: the anchor cell printed by `--list-originals` (reference
  curves) or the sheet row (performance standards) to the metric name and stratum as the
  metric library writes them (`Default` for an unstratified curve). A table without an entry
  is matched by name when exactly one record fits; `null` marks a table with no record.
- `manual` values follow the index levels 0, 0.29, 0.30, 0.69, 0.70 and 1 unless `levels` is
  given. Write them as printed (`>= 80`, `3.5 - 6.0`), leave a level blank when the source is.
- Never type an edition, citation, page, cell or unit the original does not show.

A build that used owner originals can only be checked on a machine that has them.
