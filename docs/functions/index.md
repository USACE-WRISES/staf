This list of functions is intended to be comprehensive and broadly applicable to a wide range of streams.

Most functions are assessed with a single indicator per tier. **Catchment hydrology** uses two land-cover indicators, impervious cover and agricultural land cover, and is scored automatically on whichever is more limiting for the watershed. See [Scoring and Condition](../scoring/) for how the two-indicator scoring works.
