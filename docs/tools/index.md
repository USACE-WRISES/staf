Each STAF tier has a dedicated web application. Launch any of them below — each opens in a new tab. The tools share the same 20 stream functions and scoring convention, so results stay comparable across tiers.

{% include apps_hub.html %}

## How the tools fit together
- **Screening — EASI** and **Rapid — SFARI** are each self-contained: pick a site and get a functional condition score.
- **Detailed** is a two-app workflow: build regional reference curves in **stream-curves**, export a `.deep.json` bundle, then run a site assessment against those curves in **DEEP**. DEEP can also load a pre-built state-adapted SQT.
